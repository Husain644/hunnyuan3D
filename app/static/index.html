🔒 Privacy: images and generated models are processed in memory and are not stored to disk on the server. Each GLB is served once, then discarded.
Tip: for 2mv, add front / back / left / right photos of the same object taken at the same height for the most accurate result. Front is required; the rest are optional. 2.1 needs a single image — drag in several to queue a batch.
API: POST /v1/public/generate/upload (multipart file for 2.1, or view_front/view_back/view_left/view_right for 2mv, plus model, name, description) → GET /v1/public/jobs/{id} (status) → GET /v1/public/jobs/{id}/result (GLB bytes, then purged). One GPU job at a time — queued jobs start as the active one finishes (~2–7 min each).
