🔒 Privacy: images and generated models are processed in memory and are not stored to disk on the server. Each GLB is served once, then discarded.
API: POST /v1/public/generate/upload (multipart file) → GET /v1/public/jobs/{id} (status) → GET /v1/public/jobs/{id}/result (GLB bytes, then purged). One job at a time — queued images start as the active job finishes (~4–7 min each).
